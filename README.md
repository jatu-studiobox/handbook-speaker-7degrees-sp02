# Handbook Speaker 7 Degrees SP-02 Thai Language
### วิธีใช้งาน Speaker `7 Degrees SP-02`

#### รายละเอียดช่องเชื่อมต่อทั้งหมด
* **ช่อง Micro SD (TF Card):** ช่องเสียบการ์ดหน่วยความจำขนาดเล็ก เพียงเซฟไฟล์เพลงประเภท MP3 ใส่การ์ดแล้วเสียบเข้าไป เครื่องจะเล่นเพลงให้โดยอัตโนมัติ
* **ช่อง USB (แฟลชไดรฟ์ ):** ช่องสี่เหลี่ยมขนาดใหญ่ สำหรับเสียบ Flashdrive เพื่อเปิดเพลง MP3 ได้เช่นเดียวกับการ์ด Micro SD
* **ช่อง AUX (3.5 มม.):** ช่องรูกลมขนาดเท่ารูหูฟังมาตรฐาน ใช้สำหรับเสียบสายสัญญาณเสียงเชื่อมต่อกับ คอมพิวเตอร์, โน้ตบุ๊ก หรือมือถือรุ่นเก่าที่ไม่ต้องการเปิดบลูทูธ
* **ช่อง Micro USB (ช่องชาร์จไฟ):** ช่องขนาดเล็กที่สุด ใช้สำหรับเสียบสายชาร์จเพื่อเติมแบตเตอรี่ให้กับลำโพง

#### รายละเอียดและหน้าที่ของแต่ละปุ่ม

ปุ่มกดด้านบนของลำโพง 7 Degrees SP-02 มีทั้งหมด 4 ปุ่มหลัก เรียงแถวกัน โดยสามารถฟัง "เสียงสัญญาณแจ้งเตือน" (Voice Prompt) หรือเสียงเอฟเฟกต์ตอนกด เพื่อรับรู้ว่าตัวเครื่องกำลังทำงานในโหมดใดอยู่

##### ปุ่ม ` M ` (Mode)
* หน้าที่: สลับเปลี่ยนโหมดการทำงาน
* วิธีใช้: กด 1 ครั้งเพื่อเปลี่ยนโหมดวนไปเรื่อยๆ (บลูทูธ -> วิทยุ FM -> เล่นเพลงจาก USB/Micro SD)
* วิธีสังเกต: เมื่อกดเปลี่ยนโหมด ลำโพงจะมีเสียงพูดภาษาอังกฤษบอก เช่น "Bluetooth Mode" หรือ "FM Mode"

##### ปุ่ม ` - ` (ลดเสียง / ย้อนกลับ)
* หน้าที่: ลดระดับความดัง หรือเปลี่ยนกลับไปเพลงก่อนหน้า
* วิธีใช้: กดค้าง เพื่อลดเสียง / กดปล่อยทันที เพื่อย้อนกลับไปฟังเพลงก่อนหน้าหรือย้อนสถานีวิทยุ

##### ปุ่ม ` + ` (เพิ่มเสียง / ไปข้างหน้า)
* หน้าที่: เพิ่มระดับความดัง หรือเลื่อนไปเพลงถัดไป
* วิธีใช้: กดค้าง เพื่อเพิ่มเสียง (จะมีเสียงตื๊ดเตือนเมื่อดังสุด) / กดปล่อยทันที เพื่อเปลี่ยนไปเพลงถัดไปหรือเลื่อนสถานีวิทยุ

##### ปุ่ม ` ▶|| ` (เล่น / หยุด / โทรศัพท์)
* หน้าที่: ควบคุมการเล่นเพลง, ค้นหาวิทยุ และรับสายโทรศัพท์
* วิธีใช้ในโหมดเพลง: กด 1 ครั้งเพื่อหยุดเพลงชั่วคราว หรือกดอีกครั้งเพื่อเล่นต่อ
* วิธีใช้ในโหมดวิทยุ (FM): กดค้างไว้ เครื่องจะเริ่มค้นหาและบันทึกคลื่นวิทยุในพื้นที่โดยอัตโนมัติ
* วิธีใช้ตอนมีสายเข้า: กด 1 ครั้งเพื่อรับสาย/วางสาย หรือกดค้างเพื่อปฏิเสธสาย

#### เทคนิคการลดความแรงของเสียงแจ้งเตือน
หรี่เสียงก่อนปิดเครื่อง: ก่อนจะปิดลำโพงทุกครั้ง ให้ลองกดปุ่ม - ค้างไว้ เพื่อลดเสียงของตัวลำโพงให้เบาที่สุด เมื่อเปิดเครื่องในครั้งต่อไป เสียงแจ้งเตือนจะเบาลงตามระดับเสียงล่าสุดที่ตั้งไว้ครับ

คุมระดับเสียงจากมือถือ: หลังจากเชื่อมต่อบลูทูธแล้ว แนะนำให้ปรับเสียงที่ตัวลำโพงไว้ในระดับปานกลางค่อนไปทางเบา จากนั้นให้ใช้ ปุ่มเพิ่ม-ลดเสียงบนมือถือ ในการควบคุมความดังแทน วิธีนี้จะช่วยให้คุณไม่ต้องไปยุ่งกับปุ่มที่ลำโพงบ่อยๆ ครับ
