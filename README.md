# Handbook Speaker 7 Degrees SP-02 Thai Language
### วิธีใช้งาน Speaker `7 Degrees SP-02`

#### รายละเอียดช่องเชื่อมต่อทั้งหมด
* **ช่อง Micro SD (TF Card):** ช่องเสียบการ์ดหน่วยความจำขนาดเล็ก เพียงเซฟไฟล์เพลงประเภท MP3 ใส่การ์ดแล้วเสียบเข้าไป เครื่องจะเล่นเพลงให้โดยอัตโนมัติ
* **ช่อง USB (แฟลชไดรฟ์ ):** ช่องสี่เหลี่ยมขนาดใหญ่ สำหรับเสียบ Flashdrive เพื่อเปิดเพลง MP3 ได้เช่นเดียวกับการ์ด Micro SD
* **ช่อง AUX (3.5 มม.):** ช่องรูกลมขนาดเท่ารูหูฟังมาตรฐาน ใช้สำหรับเสียบสายสัญญาณเสียงเชื่อมต่อกับ คอมพิวเตอร์, โน้ตบุ๊ก หรือมือถือรุ่นเก่าที่ไม่ต้องการเปิดบลูทูธ
* **ช่อง Micro USB (ช่องชาร์จไฟ):** ช่องขนาดเล็กที่สุด ใช้สำหรับเสียบสายชาร์จเพื่อเติมแบตเตอรี่ให้กับลำโพง

#### รายละเอียดและหน้าที่ของแต่ละปุ่ม

ปุ่มกดด้านบนของลำโพง 7 Degrees SP-02 มีทั้งหมด 4 ปุ่มหลัก เรียงแถวกัน โดยสามารถฟัง "เสียงสัญญาณแจ้งเตือน" (Voice Prompt) หรือเสียงเอฟเฟกต์ตอนกด เพื่อรับรู้ว่าตัวเครื่องกำลังทำงานในโหมดใดอยู่

##### ปุ่ม M (Mode)
* หน้าที่: สลับเปลี่ยนโหมดการทำงาน
* วิธีใช้: กด 1 ครั้งเพื่อเปลี่ยนโหมดวนไปเรื่อยๆ (บลูทูธ -> วิทยุ FM -> เล่นเพลงจาก USB/Micro SD)
* วิธีสังเกต: เมื่อกดเปลี่ยนโหมด ลำโพงจะมีเสียงพูดภาษาอังกฤษบอก เช่น "Bluetooth Mode" หรือ "FM Mode"
